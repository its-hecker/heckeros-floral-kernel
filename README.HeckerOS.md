# HeckerOS floral kernel

Exact source tree import of the CNB kernel used by the existing PixelOS coral build. UPSTREAM_SOURCE.json records the immutable source revision. Kernel code, file modes, original Linux licensing and the existing KernelSU gitlink are retained; no kernel feature changes were introduced by the HeckerOS import.

Use the [HeckerOS coral local manifest](https://github.com/its-hecker/HeckerOs-localmanifest). It enables submodule sync so KernelSU resolves to the original pinned revision. Only coral is registered for the first HeckerOS integration. Full ROM build and phone validation are pending.
